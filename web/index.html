tabernetes source

A Kubernetes cluster whose nodes are browser tabs

Open the page and your phone is a node. The scheduler sends it a pod, and the pod's program runs on a Linux kernel booted in the tab. Close the tab and the node is gone, and Kubernetes starts the pod on someone else's.

Scan to become a node, or use the browser you are reading this in.

Join the cluster

Joining downloads about 5 MB and runs a small Linux guest in the tab, on one core, until you close the tab.

          How it works

          The control plane is an ordinary Kubernetes on one small machine. Beside it runs an agent that plays kubelet for every tab at once. A tab that opens the join page gets a Node. When the scheduler binds a pod to that Node, the agent starts the pod's container with tabc, a container runtime that runs each container in a browser tab, and the tab loads the container's page.

          The tab supplies the CPU and the memory. The container's files and its network stay on the machine: every connection the program makes leaves from the pod's own address there, so a Service reaches a pod on a phone like any other pod. 

          apiVersion: v1
kind: Pod
metadata:
  name: hello
spec:
  runtimeClassName: tab
  containers:
    - name: hello
      image: alpine
      command: ["sh", "-c", "echo hello from $(uname -m) in a tab; sleep 3600"]

          A node's place on the globe is the city its browser's time zone is named after, and nothing finer: the site does not look up anyone's address. The land is Natural Earth's.
